Canary USB Sentinel es un script avanzado de monitorización táctica en PowerShell, diseñado para la detección en tiempo real de amenazas (IoC) en dispositivos de almacenamiento externo USB.

🚀 Funcionalidades
Monitorización en Tiempo Real: Detecta la inserción de hardware instantáneamente mediante eventos WMI.

Escaneo de Amenazas: Identifica extensiones críticas (.exe, .bat, .vbs, .ps1, .lnk, .run) y archivos ocultos sospechosos.

Aislamiento Automático: Expulsa la unidad automáticamente si detecta un patrón malicioso o archivos de auto-arranque.

Auditoría Forense: Genera un log detallado de cada alerta directamente en tu Escritorio.

🛠️ Instalación y Uso
Descarga el archivo Canary_USB_Scanner.ps1.

Ejecuta PowerShell como Administrador.

Lanza el script:

.\Canary_USB_Scanner.ps1
